# Settings Page Override

## Goal

Expose operational configuration without becoming a full model-management console.

## v0.1 sections

- OpenCode and model profile
- Monitoring defaults
- Data retention
- Startup behavior

## Rules

- Use list rows rather than card-per-setting.
- Show current health and last validation time.
- API credential replacement is explicit; never display the stored value.
- Security test action is secondary, not destructive.

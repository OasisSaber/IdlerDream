# Inspection Panel Override

## Goal

Let the user understand that a read-only inspection is active without exposing source code or hidden model reasoning.

## Required content

- Project name
- Current safe stage
- Last safe activity summary
- Elapsed time
- File/tool budgets
- Cancel button

## Rules

- Nonmodal and anchored to the window edge.
- No raw stream, source excerpt, prompt or chain-of-thought.
- Reduce or remove orbit animation when reduced motion is requested.
- Cancel must be available at all stages.
